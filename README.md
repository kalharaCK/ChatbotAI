# AI Personal Assistant with Calendar & Task Management

A modern, AI-powered personal assistant that combines task management, calendar scheduling, and natural conversation capabilities. Built with React, TypeScript, and Google's Gemini AI.



## Features

### 🤖 AI Assistant
- Natural language conversation with Gemini AI
- Voice interaction support
- File upload capabilities
- Customizable assistant name
- Real-time animated expressions
- Voice mode toggle
- Auto-scroll conversations

### 📅 Calendar Management
- Interactive monthly calendar view
- Event creation and management
- Visual event indicators
- Quick date navigation
- Responsive design for all devices
- Event descriptions and details

### ✅ Task Management
- Priority-based task organization
- Due date tracking
- Task filtering (All/Active/Completed)
- Visual priority indicators
- Task completion tracking
- Task notifications

### 🎨 Modern UI/UX
- Dark theme optimized for eye comfort
- Responsive design for all devices
- Smooth animations and transitions
- Intuitive interface
- Professional and clean layout

## Technology Stack

- **Frontend**: React + TypeScript
- **Styling**: Tailwind CSS
- **AI**: Google Gemini AI
- **Animations**: Lottie
- **Voice**: Web Speech API
- **State Management**: React Hooks
- **Date Handling**: date-fns
- **Icons**: Lucide React

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file with your Google AI API key:
   ```
   VITE_GOOGLE_AI_KEY=your_api_key_here
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

## Usage

1. **Initial Setup**
   - Enter your name
   - Choose a name for your AI assistant (default: QT)

2. **AI Conversation**
   - Type messages or use voice input
   - Toggle voice mode for spoken responses
   - Upload files for AI analysis

3. **Calendar Management**
   - Click any date to add events
   - Navigate months using arrows
   - View event details in the calendar

4. **Task Management**
   - Add tasks with priorities and due dates
   - Filter tasks by status
   - Mark tasks as complete
   - Delete tasks when needed
